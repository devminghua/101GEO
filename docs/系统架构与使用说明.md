## 一、系统架构（五层）

```
┌─────────────────────────────────────────────────────────┐
│ 入口层    分站客户端（GEO/国际/创作）   总后台 super（客户管理/安全检测） │
├─────────────────────────────────────────────────────────┤
│ 前端层    React SPA（内嵌于后端 webdist）Arco Design · i18n 四语言 · EChart │
├─────────────────────────────────────────────────────────┤
│ 后端层    Go 单二进制（gin）                              │
│   ├ GEO 智能中心   巡检 · 仪表盘 · 工作日志              │
│   ├ 百度优化       分析 · 监控 · 收录 · 体检             │
│   ├ 国际搜索优化   Google/Naver 六模块（独立配额/数据）  │
│   ├ 短视频获客     抖音 · 快手 · 小红书                 │
│   ├ 智能创作中心   文案 · 脚本 · 文生图                 │
│   ├ 安全检测（super）Nmap 端口 · sqlmap 注入            │
│   └ 公共底座       多租户隔离 · 配额点卡 · AI 平台归属 · biztime │
├─────────────────────────────────────────────────────────┤
│ 数据层    PostgreSQL（租户数据/快照/账本）  sqlmapapi（守护自愈）  文件存储 │
├─────────────────────────────────────────────────────────┤
│ 外部层    百度 SERP（反爬代理）  AI 平台（客户 Key）                 │
│           Serper/SerpAPI（Google/Naver SERP）  Datalab/GSC（官方趋势/收录） │
└─────────────────────────────────────────────────────────┘
```

**核心设计**：单文件部署——前端构建产物内嵌 Go 二进制，一个文件 + docker compose 即全套系统。

## 二、使用说明

### 2.1 部署（服务器版）

```bash
# 1. 上传并解压
tar -xzf LinkGeo-server-v1.0.65.tar.gz && cd LinkGeo-server-v1.0.65

# 2. 一键启动（应用 + PostgreSQL）
docker compose up -d

# 3. 验证
curl http://127.0.0.1:8080/api/system/info   # 返回 version 字段即成功
```

浏览器访问 `http://服务器IP:8080`。首次部署建议修改 compose 里的 3 处密钥（JWT / 数据加密 / 数据库密码）。

### 2.3 各模块配置要点

| 模块 | 需要的配置 | 位置 |
|---|---|---|
| AI 能力（巡检/助手/创作） | AI 平台（分站自备 Key） | 分站「AI 平台」页 |
| 百度优化 | 无需配置（反爬代理已内置） | — |
| 国际搜索优化 | Serper / SerpAPI / Datalab 凭据 | 国际菜单底部「数据源设置」（分站自备优先，平台默认兜底） |
| 短视频获客 | Just One API token | 总后台「数据 API」页 |
| 安全检测（Nmap/sqlmap） | 无需配置（引擎内置） | 总后台侧栏「安全检测」 |
| 短信 | 阿里云 SMS | 总后台「短信设置」 |

### 2.4 配额与计费口径

- 每日查询配额分池：**total**（百度）、**intl**（国际）、**short_video**（短视频）、**portscan**（端口扫描 5 次/天）、**sqlmap**（注入检测 3 次/天）——各池独立计数
- AI 调用走点卡 token 账本：先校验依赖 → 扣费 → 调用 → 失败退款（净消耗 = Σsample_count − Σrefunded_points）

## 四、铁律（开发必守）

1. **版本号**：每次改动递增（三处同步：config.go / 开发文档 / changelog.go），先改版本再编译再部署
2. **口径唯一**：同一逻辑只一个权威实现，新功能先 grep 是否已有同语义代码
3. **先校验 → 扣费 → 调用 → 失败退款**；失败文案区分我方问题与客户需处理问题
4. **分站自备 Key 自付费用**：AI 平台与数据源 Key 均租户级优先，平台配置只兜底
5. **时区**：按天业务一律 biztime（北京），time.Now() 仅绝对时刻
6. **更新前备份**：`bash scripts/backup-db.sh` 见 [OK] 才动
7. **验证副作用归还**：测试消耗的配额/数据必须清理归还
