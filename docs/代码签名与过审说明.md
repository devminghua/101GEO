# LinkGeo 安装包过审 / 代码签名说明

> 目标：让 Windows / macOS 安装包「不提示危险 / 未验证开发者」。
> 结论：**必须使用付费代码签名证书**，这是操作系统安全机制，无免费绕过办法。

---

## 一、为什么会出现「危险」提示

两个平台各有独立的安全拦截机制：

| 平台 | 机制 | 未签名的表现 |
|---|---|---|
| Windows | SmartScreen（智能屏幕） | 下载提示「可能有害」、运行提示「Windows 已保护你的电脑」 |
| macOS | Gatekeeper（门卫） | 双击提示「无法打开，因为无法验证开发者」 |

判断依据是**可执行文件是否带有可信发布者的数字签名**。没有签名 = 系统默认不信任 = 提示危险。

---

## 二、要彻底消除提示，需要什么

### Windows（消除 SmartScreen 提示）
需要 **代码签名证书**（Code Signing Certificate）：

| 证书类型 | 费用（参考） | 效果 |
|---|---|---|
| OV 证书 | 约 ¥1000-2000/年 | 显示公司名，但 SmartScreen 初期仍可能提示（需累积下载信誉） |
| **EV 证书**（推荐） | 约 ¥3000-5000/年 | 立即获得 SmartScreen 信誉，基本不提示「未知发布者」 |

推荐供应商：DigiCert、GlobalSign、Sectigo、亚洲诚信（TrustAsia，国内可代办）。

### macOS（消除 Gatekeeper 提示）
需要 **Apple Developer ID 证书** + **公证（notarization）**：

1. 注册 Apple Developer Program：**99 美元/年**
2. 在开发者后台创建「Developer ID Application」证书
3. 用该证书对 App 签名
4. 提交公证：`xcrun notarytool submit --apple-id ... --password ... LinkGeo.dmg`
5. 公证通过后，下载的 App 不再被 Gatekeeper 拦截

## 三、没有证书时，我已经做了的缓解（当前四件套）

1. ✅ **加了应用图标**（Windows .ico + macOS .icns），外观正规、不再「裸 exe」。
2. ✅ **macOS ad-hoc 签名**（codesign），一定程度改善，但仍会提示「无法验证开发者」。
3. ❗ **用户侧手动绕过的临时办法**（可写进使用说明）：
   - Windows：下载后点「更多信息」→「仍要运行」。
   - macOS：右键 App →「打开」→ 再点「打开」（或系统设置 → 隐私与安全性 →「仍要打开」）。

---

## 四、拿到证书后，我来做（一键）

老板拿到证书后，把证书文件（.pfx/.p12 或 .cer+.key）给我，我负责：

- Windows：用证书签名 `LinkGeo-Setup.exe` 和 `LinkGeo.exe`（`osslsigncode` / `signtool`）。
- macOS：用 Developer ID 证书签名 + 提交公证（`codesign` + `notarytool`）。
- 签名后重新打包四件套。

## 五、结论

| 需求 | 能否实现 | 前提 |
|---|---|---|
| 加图标、正规外观 | ✅ 已完成 | 无 |
| 彻底不提示「危险」 | ✅ 可以 | **需要付费代码签名证书**（Windows + macOS 各一套） |
| 无证书消除提示 | ❌ 做不到 | 操作系统强制机制，无绕过 |

**建议**：先按当前版本（含图标 + ad-hoc 签名 + 使用说明里的绕过指引）分发；正式大规模对外时，购买证书（建议 Windows EV 证书 + Apple Developer ID），交给我做正式签名 + 公证。
