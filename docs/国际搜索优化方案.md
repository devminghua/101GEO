# 国际搜索优化（Google / Naver）方案

> 版本：v1.0.65 规划稿 ｜ 2026-09-14 ｜ 供老板拍板后实施

---

## 1. 栏目设计

在客户端侧栏新增 **「国际搜索优化」** 下拉栏目（与「百度优化」平级），下设两个子模块：

```
国际搜索优化
├── Google 优化
│   ├── 关键词分析（SERP 抓取 + 霸屏/同行分析）
│   ├── 排名监控（快照 + 趋势）
│   ├── 收录查询（GSC 权威数据）
│   ├── 站点体检（GSC 诊断）
│   ├── 差距诊断（vs 竞品）
│   └── 行业排行（Trends/搜索热度）
└── Naver 优化（同上六项，韩国市场）
```

> 说明：与「百度优化」六页一一对应，交互完全一致——客户学习成本为零，海外业务直接上手。总后台「数据 API」页增加 Google/Naver 的 API Key 配置位。

## 2. 接口方案（用什么、多少钱、什么数据）

### 2.1 Google 接口盘点

| 能力 | 接口 | 类型 | 成本 | 说明 |
|---|---|---|---|---|
| **SERP 抓取（排名快照）** | Serper.dev | 第三方 | 2500 次免费，之后 $0.30/千次 | 首选。返回结构化 JSON（自然结果/广告/位置），无需站点验证 |
| | SerpAPI | 第三方 | $50/月 或按次 | 备选。聚合器老牌，`engine=google` |
| | Google Custom Search JSON | 官方 | 100 次/天免费，超量 $5/千次 | 只返回与站点相关的搜索结果，不是完整 SERP，适合做「出现次数」小规模核对 |
| **收录 / 真实排名 / 点击** | Google Search Console API | 官方免费 | 每天约 1200 次查询配额 | **权威源**。查询词、点击、展示、排名位置、收录状态、站点地图、核心网页指标。需客户完成站点验证授权（OAuth） |
| **AI 平台** | Gemini API | 官方 | 有免费档 + 按量 | 走现有 ai_platform（OpenAI 兼容端点或官方 SDK） |
| **行业热度** | Google Trends | 非官方库（pytrends） | 免费（有风控） | 趋势/地区热度；也可用 Serper/SerpAPI 的 trends 附加能力 |

### 2.2 Naver 接口盘点

| 能力 | 接口 | 类型 | 成本 | 说明 |
|---|---|---|---|---|
| **SERP 抓取（排名快照）** | SerpAPI（engine=naver） | 第三方 | $50/月 或按次 | 首选。Serper 不支持 Naver，Naver SERP 只能走 SerpAPI/Bright Data |
| | Bright Data / Crawlbase | 第三方 | 按次，韩国较贵 | 备选。适合量大时 |
| **收录 / 真实排名 / 查询词** | Naver Search Advisor API | 官方免费 | 免费（需网站管理员注册+站点验证） | **权威源**。与 GSC 对应，提供查询词/排名/收录 |
| | Naver 검색 API（搜索 API） | 官方 | 需申请，配额制 | 仅分类搜索（블로그/뉴스/知识in），**不是通用网页 SERP**，不适用排名监测，放弃 |
| **AI 平台** | HyperCLOVA X | Naver Cloud | 按量，需 NCP 账号申请（企业资质） | 走 OpenAI 兼容端点；无资质时用 Gemini/其它韩语模型替代 |

### 2.3 选型结论（默认方案）

| 层 | 选择 | 理由 |
|---|---|---|
| SERP 快照 | **Serper.dev（Google）+ SerpAPI（Naver）** | 无需站点验证、返回结构化数据、按量便宜、与我们「先扣费后调用+失败退款」计费体系天然契合 |
| 权威数据 | **GSC + Naver Search Advisor**（P3 阶段） | 免费且权威；作为「收录查询/站点体检」数据源，SERP API 只负责快照 |
| AI 平台 | **Gemini + HyperCLOVA X** | 直接进现有 ai_platform 体系，零新代码 |
| 行业排行 | Trends（Google）/ 第三方（Naver 无官方，用 SERP 热度兜底） | P4 阶段 |

## 3. 架构落地（复用现有管线，口径唯一）

### 3.1 多引擎抓取适配器

现有管线：`baidu.fetcher（HTTP抓取）→ parser（HTML解析）→ analyzer（BuildResult/GenAdvice 霸屏分析+建议）`。

**改法**：新增 `services/serp` 统一接口，把「引擎差异」收敛到适配器层，分析层零改动：

```
services/serp/
├── engine.go      // 统一接口：Fetch(keyword, page, engine) → []PageInfo（引擎枚举：baidu/google/naver）
├── baidu.go       // 现有 HTTP 抓取逻辑迁入（不动行为）
├── google.go      // 调 Serper.dev API → JSON → PageInfo（自然结果/广告位/域名/标题）
├── naver.go       // 调 SerpAPI(engine=naver) → JSON → PageInfo
└── client.go      // API Key 管理（总后台配置，容器 DB 为唯一权威源）+ 限流 + 扣费/退款
```

- `PageInfo`/`PeerRow` 结构不变 → `analyzer.BuildResult`、`GenAdvice`、霸屏统计**直接复用**，Google/Naver 的关键词分析、差距诊断、建议生成第一版就完整。
- 百度原有 `fetcher.go` 仅做搬家，不产生第二套实现。

### 3.2 数据模型

- 关键词/快照表加 `engine` 字段（`baidu`/`google`/`naver`），复用 `baidu_monitor`/快照表与巡检任务体系，**不新建平行表**。
- 新增 `intl_auth` 表：GSC/NSA 授权凭据（P3 用，暂不建）。

### 3.3 配额与计费

- 复用每日查询配额体系：**国际查询独立配额池，默认 3 次/天**（与百度口径一致），总后台客户管理可调。
- 每次 Google/Naver 抓取走「先扣费 → 调用 → 失败退款」铁律；SERP API 有真实成本（Serper $0.3/千次），每查询扣 1 token 与现有计量统一。

### 3.4 巡检

- 国际关键词纳入现有巡检调度（复用 `check_tasks`，按 engine 路由到对应适配器），熔断/超时保护/退款全继承。

## 4. 分阶段实施（每轮一个可上线版本）

| 阶段 | 内容 | 版本 |
|---|---|---|
| **P1** | 「国际搜索优化」栏目 + Google 关键词分析（Serper 接入 + analyzer 复用 + 配额计费）+ Gemini 平台接入 + 总后台数据 API 配置位 | 1.0.66 |
| **P2** | Google 排名监控（快照/趋势）+ Naver 关键词分析（SerpAPI 接入） | 1.0.67 |
| **P3** | GSC + Naver Search Advisor 授权接入：收录查询、真实排名、站点体检（官方免费权威数据） | 1.0.68 |
| **P4** | 差距诊断 + 建议生成（复用 analyzer）+ 行业排行（Trends）+ 多语言界面覆盖 | 1.0.69+ |

## 5. 成本预估（上线参考）

| 项 | 预估 |
|---|---|
| Serper.dev | 2500 次免费起步；假设全平台每日 100 次国际查询 ≈ 3000 次/月 ≈ **$1/月** |
| SerpAPI（Naver） | $50/月套餐（5000 次）或按次计费；Naver 用量小可先按次 |
| Gemini / HyperCLOVA X | 按客户自备 Key 计费（分站自付，与现有 AI 平台规则一致） |
| GSC / Naver Search Advisor | 免费 |

> 成本极低且可随用量线性扩展；API Key 全部配置在总后台（容器 DB 权威源），分站不可见。

## 6. 风险与对策

| 风险 | 对策 |
|---|---|
| Google SERP 风控 | Serper 是官方授权数据通道，非爬虫，无封禁风险 |
| Naver 无廉价 SERP 源 | 排名数据优先用 Search Advisor 官方源（P3），SERP 快照仅做霸屏分析 |
| GSC 授权门槛（站点验证） | 设计「一键 OAuth 引导」+ 未授权时降级为 SERP API 快照数据 |
| 韩国企业资质（CLOVA X） | 无资质客户默认 Gemini/通用模型，功能不阻塞 |
