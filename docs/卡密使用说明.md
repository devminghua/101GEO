# LinkGeo 卡密授权 · 使用说明

> 面向：老板（生成卡密）与客户（激活软件）

---

## 一、授权机制（一句话）

Windows 客户端首次启动需**输入卡密激活**，激活后按卡密类型开通使用时长（3 天试用 / 12 个月），到期后需新卡密续费。

卡密采用 **Ed25519 非对称签名**：私钥只在老板手里（生成卡密），客户端只内置公钥（验签），**卡密不可伪造、不可枚举**。

---

## 二、老板：如何生成卡密

### 方式一：总后台界面（推荐）

1. 登录总后台（super 账号）→ 左侧菜单「卡密管理」。
2. 首次使用：点击「导入私钥」，粘贴 `release/LinkGeo-卡密私钥-请老板保管.txt` 里的私钥。
3. 在「批量生成卡密」中选择类型 + 数量，点击「生成」。
4. 点击「下载 txt」导出卡密串，发给客户。

### 方式二：命令行（备选）

```bash
cd geo-tool/backend
go run ./cmd/gencard -priv "<私钥>" -n 1000 -tier 2   # 1000 张 12 个月卡
go run ./cmd/gencard -priv "<私钥>" -n 7000 -tier 1   # 7000 张 3 天试用卡
```

类型：`tier 1` = 3 天试用；`tier 2` = 12 个月。

---

## 三、客户：如何激活

1. 安装 / 解压后，双击启动 LinkGeo。
2. 浏览器自动打开激活页，输入卡密，点击「立即激活」。
3. 激活成功页面显示**到期时间**与**管理员初始密码**（请客户妥善保存）。
4. 点击「前往登录」，用 `admin` + 初始密码登录。

> 卡密规则：一张卡密只能用一次（首次激活即开始计时）；到期后重新进入激活页，用新卡密续费。

---

## 四、安全边界（务必知悉）

| 防护 | 效果 |
|---|---|
| 伪造 / 枚举卡密 | ✅ 防住（无私钥无法伪造） |
| 同一卡密重复使用 / 囤卡 | ✅ 防住（卡密序号防重 + 首次激活计时） |
| 改数据库字段白嫖（改到期时间） | ✅ 防住（授权数据 HMAC 签名校验，篡改即「授权数据异常」） |
| 逆向 exe 直接 patch 破解 | ❌ 防不住（离线软件固有局限，只能靠后续在线授权） |

**重要**：私钥文件 `LinkGeo-卡密私钥-请老板保管.txt` 请单独妥善保存，**不要随源码包 / 客户端安装包一起分发给客户**。

---

## 五、密钥对与打包关系

- 客户端安装包 / 便携版在打包时已内置**公钥**（`GEO_LICENSE_PUBLIC_KEY`）。
- 老板生成卡密必须用**对应的私钥**（本说明第二节）。
- 若重新生成密钥对，则**旧卡密全部失效**，需重新生成卡密并重新打包客户端。
