## 4. 部署方式 A：单二进制（SQLite）

### 4.1 产物

| 文件 | 说明 |
|---|---|
| `geotool`（Linux 二进制） | 静态链接，约 21MB；`uname -m` 判断 amd64/arm64 |
| `geo-tool.db`（可选） | 已有数据迁移时上传 |

### 4.2 目录与启动

```bash
sudo mkdir -p /opt/geo-tool/{backend,data}
# 上传二进制到 /opt/geo-tool/backend/geotool
chmod +x /opt/geo-tool/backend/geotool

# 环境变量 backend/.env
cat > /opt/geo-tool/backend/.env <<'EOF'
GEO_PORT=8080
GEO_DB_PATH=../data/geo-tool.db
GEO_DEFAULT_BRAND=你的品牌词
GEO_CRON_ENABLED=true
GEO_CRON_MINUTES=60
GEO_JWT_SECRET=$(openssl rand -hex 32)
GEO_SECRET_KEY=$(openssl rand -hex 32)
EOF
```

### 4.3 systemd 守护

```ini
# /etc/systemd/system/geotool.service
[Unit]
Description=LinkGeo Backend
After=network.target

[Service]
Type=simple
WorkingDirectory=/opt/geo-tool/backend
ExecStart=/opt/geo-tool/backend/geotool
Restart=always
RestartSec=3
EnvironmentFile=/opt/geo-tool/backend/.env

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now geotool
```

## 5. 部署方式 B：Docker Compose（PostgreSQL）

### 5.1 服务编排（docker-compose.yml 核心）

```yaml
services:
  geotool:
    image: geotool:latest
    container_name: geotool
    restart: unless-stopped
    ports:
      - "8080:8080"          # 生产建议改为 127.0.0.1:8080:8080，仅本机
    environment:
      GEO_PORT: "8080"
      GEO_DB_DRIVER: "postgres"
      GEO_DB_DSN: "host=postgres port=5432 user=postgres password=<强密码> dbname=geotool sslmode=disable"
      GEO_CRON_ENABLED: "true"
      GEO_CRON_MINUTES: "60"
      GEO_JWT_SECRET: "<openssl rand -hex 32>"
      GEO_SECRET_KEY: "<openssl rand -hex 32>"
      GEO_BAIDU_PROXY: "http://host.docker.internal:18888"  # 百度抓取出口代理
    volumes:
      - ./uploads:/app/backend/uploads
    depends_on:
      - postgres

  postgres:
    image: postgres:16-alpine
    container_name: geotool-postgres
    restart: unless-stopped
    environment:
      POSTGRES_PASSWORD: "<强密码>"
      POSTGRES_DB: "geotool"
    volumes:
      - ./pgdata:/var/lib/postgresql/data
    # 不映射 5432 到宿主机，仅容器内网访问
```

### 5.2 构建镜像（多阶段）

Dockerfile 三个阶段：`node:20-alpine` 构建前端 → `golang:1.25-alpine` 构建后端（go:embed webdist）→ `alpine:3.20` 运行（含 sqlite CLI 用于容器内备份）。

```bash
docker build -t geotool:latest .
docker compose up -d
```

## 7. Nginx 反向代理 + HTTPS

```nginx
server {
    listen 80;
    server_name geo.example.com;
    # HTTP 强制跳 HTTPS（certbot 会自动加 443 段）
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl http2;
    server_name geo.example.com;

    ssl_certificate     /etc/letsencrypt/live/geo.example.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/geo.example.com/privkey.pem;

    client_max_body_size 50m;   # 创作中心上传图片/视频

    location / {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        # 长连接/SSE 支持（如需）
        proxy_read_timeout 300s;
    }
}
```

HTTPS 证书（Let's Encrypt 免费）：

```bash
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d geo.example.com
# 自动续期
sudo systemctl enable --now certbot.timer
```

> 前端为 SPA：所有未匹配 `/api`、`/uploads` 的 GET 由后端兜底返回 index.html，无需在 Nginx 单独配 try_files。

## 9. 数据备份与迁移

### 9.1 SQLite 模式

```bash
# 单文件直接拷贝（建议先停写或低峰）
cp /opt/geo-tool/data/geo-tool.db /backup/geo-tool-$(date +%F).db
```

### 9.2 PostgreSQL 模式

```bash
# 容器内 pg_dump
docker exec geotool-postgres pg_dump -U postgres -d geotool > /backup/geotool-$(date +%F).sql
```

> 项目内 `scripts/backup-db.sh` 已封装 SQLite（dev/docker）备份流程，见 `[OK]` 才可操作数据。

### 9.3 迁移要点

1. 数据库与 `uploads/`（Logo、创作中心素材）需同步迁移。
2. `GEO_SECRET_KEY` / `GEO_JWT_SECRET` 必须与旧环境一致。
3. 数据库是唯一权威源；**严禁**用开发库反向覆盖容器库。

## 12. 常见问题

| 现象 | 处理 |
|---|---|
| 启动即退出 | 查日志；确认 8080 未被占用（`ss -ltnp`） |
| 接口 404 / 白屏 | 确认二进制内嵌 dist 版本正确；相对路径正确 |
| 上传图片 404 | 确认 `uploads/` 目录可写、挂载正确 |
| 数据库锁 / WAL 报错 | SQLite 模式确认 journal_mode=truncate；PG 模式确认连接池配置 |
| 百度抓取被反爬 | 确认 `GEO_BAIDU_PROXY` 转发服务已启动 |
| 短信收不到 | 确认阿里云 AccessKey/签名/模板配置 + 余额 |
